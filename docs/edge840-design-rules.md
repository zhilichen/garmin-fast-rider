# Edge 840 原生像素规则（v0.3.7）

项目设计基线，适用于246×322单字段全屏。不是Garmin官方最小尺寸规定。[当前矢量稿](design/summit-interactive.svg)。

- 内容外边距2 px；Lap顶帽极端位置仍至少留1 px。竖分隔统一x122，宽2 px。
- 主数字58 px，左对齐x2/x126、baseline43，Edge840抗锯齿后可见字形顶部y2；四位功率回退36 px以避让雷达。
- 右上x218…245/y0…33保持空白。红心16×14 px、闪电14×14 px，均在单位行，底端y62，紧邻bpm/W文字并同基线。
- Zone为14 px小Z+44 px区号，总宽30 px、baseline66，留在雷达下方；四位主数字36 px时改用9 px小Z+26 px区号，总宽19 px，右对齐x120/x244；单位18 px、baseline62。色条x2/x126、y76，118×6 px；标记4×22 px、y68…89，上下8px黑色，中段6px白色。
- 中间左2×2：列中心x31/x92，标签baseline106/170、数值149/212；数值38 px加粗。窄格先舍去小数，不裁切数字。
- 右中：x126…244；标题baseline105，计时132（32 px，超长30/26 px），均功率180（54 px，四位36 px），距离212（数字32 px、常规mi18 px；All有有效导航距离时追加21 px蓝色常规剩余数值，约2/3高度，长值成对缩小）。AVG/W紧随功率数字，间距3 px。
- 图区从y220开始；分隔x2…243。左侧累计爬升x2，范围中心x123，完整AM/PM时钟右对齐x244，baseline238，均18 px；爬升数字加粗，ft常规。没有总时长与底栏文字。
- 功率图x4…242、y243…319，高77 px；曲线和Lap边界延伸到319，底部留下2 px。FTP虚线和Z2实线随新纵轴映射，阈值不变。
- 图标和曲线启用原生图形抗锯齿；字体采用灰度覆盖率字库并开启抗锯齿导入、按实际白底绘制；每次文字绘制只裁剪到实际字形上下界，防止逻辑行框覆盖邻行。整数像素上的色条和分隔线保持锐利。
- 白底，主要文字#15212B，辅助#354550；图填充白底90%不透明。彩色数字/色条/曲线共享高饱和色板，灰色为中性灰；颜色分组与色值见README。

点击区：功率(124,0)–(246,90)，统计(124,91)–(246,214)，图表(0,220)–(246,320)，右/下界不含。左侧x<122/y<214的双击用于电子铃声，单击不切换数据。图表最底部也能切换范围；最后2 px留白不响应。切换不清空数据，默认3s/All/5m。

验收使用原生Dc字宽、VM绘制和模拟器Save Screen Capture截图；真机雷达覆盖、太阳光/眼镜下可读性及长骑仍由Edge840实测。
