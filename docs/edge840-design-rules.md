# Edge 840 原生像素规则（v0.3.11）

项目设计基线，适用于246×322单字段全屏。不是Garmin官方最小尺寸规定。[当前矢量稿](design/summit-interactive.svg)。

- 外边距2 px；上下竖分隔统一x107、宽2 px，较此前x122左移15 px。左内容x2…105、可用103 px；右内容x111…244、可用133 px。
- 主数字仍58 px，左对齐x2/x111，baseline43；心率三位数使用相同58 px字形、仅字符间距收紧3 px；四位功率仍36 px回退。右上x218…245/y0…33保持空白。
- 红心16×14、闪电14×14，仍在baseline62单位行，紧邻bpm/W。Zone仍16 px加厚小Z+44 px区号，总宽31 px、baseline66；四位主值时10/26 px，总宽20 px。心率Zone右对齐x105，功率右对齐x244。
- 色条y76、h6，心率x2/w103、功率x111/w133；4×22 px位置标记按各自条宽映射，上下8px黑色、中段6px白色。
- 中间左2×2中心x27/x79，标签baseline106/170，值149/212；字号仍38 px加粗，仅字符间距收紧2 px，可显示三位踏频。窄格有效文字预算51 px，速度/坡度先舍去小数，不压缩字形。
- 右中标题x111/baseline105，时长右对齐244/baseline132。均功率+AVG/W整组在133 px面板内居中，间距3 px。距离+mi+剩余距离同样整组居中，单位两侧各3 px。字号和原118 px字体回退条件不变。
- 图头baseline238：爬升x2，带蓝色14×14 px闪电的`< ⚡ 5m >`（20m/All同格式）整组居中x123，完整AM/PM时钟右对齐244；文字18 px，爬升数字粗体、ft常规。无总时长或底栏文字。
- 功率图x4…242/y243…319，高77 px；FTP虚线、Z2实线及Lap标记规则不变。图标/字体保留抗锯齿，文字仅在实际字形边界裁剪；整数像素色条和分隔保持锐利。
- 高饱和配色和90%图表填充保持不变；颜色分组见README。

点击区：功率(109,0)–(246,90)，统计(109,91)–(246,214)，图表(0,220)–(246,320)，右/下界不含。x107…108为分隔，不响应；左侧x<107/y<214双击车铃，单击不切换。新获得的15 px右侧区域也立即响应切换。默认3s/All/5m不变。

验收使用原生Dc字宽、VM绘制和模拟器Save Screen Capture截图；真实屏幕、雷达覆盖及日照下可读性仍由Edge840实测。
