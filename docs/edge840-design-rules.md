# Edge 840：原生像素矢量图元规则

这是一套用于骑行数据页的**项目设计基线**，不是 Garmin 官方最小尺寸规定。目标是在原生 246 × 322 像素下保留可辨认的字形、线条和位置标记。锁屏、室内截图和放大的预览都不能替代车把安装后的实机验证。

## 画布与尺度

Garmin 公布的 Edge 840 屏幕为 **246 × 322，矩形、半透反射式高彩色 LCD**。[官方设备列表](https://developer.garmin.com/connect-iq/compatible-devices/)。本机官方设备包给出的 `ppi` 为 156，因此 1 物理像素约 0.163 mm；这是估算尺寸，最终落点仍以像素为准。

- 设计稿与 SVG 一律 `viewBox="0 0 246 322"`。模拟器导出的验收图片必须恰好是 246 × 322。
- **1 px 是落点单位，2 px 是布局单位。** 边距、间隔、矩形尺寸优先取 2 的倍数；曲线采样点、光学居中和奇数宽标记允许落在任意整数像素上。
- 浮点坐标在提交绘图前四舍五入一次；不把轮廓位置留在小数像素上。缩小后的 1.5 px 笔画不作为合格的 2 px 笔画。
- 不把其他尺寸的界面整体缩到 Edge 840。不满足原生全屏尺寸时，提示选择单字段布局。
- 安全边距 **8 px**；主列可用宽度 **108 px**，左右起点为 **8 / 130 px**，中间分隔为 `x=122, w=2`。

## 最小图元

| 图元 | 最小规则 | 当前页面取值 |
| --- | --- | --- |
| 可传达信息的轮廓线 | **2 px**；不使用 1 px hairline | 海拔轮廓、分隔线 2 px |
| 当前位置竖线 | **3 px**，明确高于普通轮廓 | 3 px 实心矩形 |
| Zone 色条 | **4 px 高**，不能只靠色条传达区间 | 108 × 4，加 Z1–Z7 文本 |
| 独立小点 | 至少 **6 × 6 px** 占位 | 不用 1–3 px 点表达当前位置 |
| 关键位置标记 | 至少 **14 × 14 px** 占位 | 实心圆半径 6，白色内孔半径 2 |
| 标记隔离带 | **2 px** 白色 halo，周边不得截断 | 外层白圆半径 8，约 18 × 18 px 安全占位 |
| 一般图标 | 至少 **16 × 16 px**；首选 24 × 24 | 轮廓 2，内部留白至少 4 |
| 相邻独立形状间距 | **4 px**；通常 8 px | 标签与数字至少 4 px；区域间 8 px 起 |
| 负空间 / 镂空孔 | 至少 **4 px** 宽或高 | 位置圆环内孔直径约 4–5 px |
| 圆角 | 常规 4 px；图标最多保留两级形状 | 不加入小于 4 px 的装饰性凹口 |

圆的边界是否包含端点取决于光栅器，因此规范同时给出半径和安全占位，而不把 `r=6` 武断等同于严格的 12 像素直径。

连续海拔区域内部可以用 1 px 列填色；这些列合并后是一整块面积，**不是 1 px 语义线**。先完成全部填色，再画 2 px 轮廓，避免后一列把前一列的粗线覆盖掉。

小图标使用轮廓或剪影，只保留主体和最多一个关键特征。禁止阴影、渐变、高光、纹理和依赖抗锯齿才存在的细节。35 × 35 的启动图标是 Garmin 的资源尺寸要求，内部仍遵守上述笔画/留白原则。

矢量图元校准卡：[edge840-atoms.svg](design/edge840-atoms.svg)。此卡本身也是 246 × 322，建议按 100% 和整数倍查看。

## 文字：验收可见字高，不只看字号名称

旧截图中 POWER、HEART RATE、距离标签和坐标说明的可见字高只有 **8 px**。`FONT_XTINY`、`FONT_SMALL` 等名称并不能替代实际像素测量，`getFontHeight()` 也包含字形外的排版空间。

| 层级 | 可见大写/数字字高基线 | 使用规则 |
| --- | --- | --- |
| 功率 / 心率主数值 | 常态约 **34 px**，下限 **26 px** | HOT → MEDIUM；禁止降到标签字体 |
| 踏频 / 横幅坡度 | 至少 **22 px** | 踏频使用 NUMBER_MEDIUM（约 26 px），坡度 NUMBER_MILD |
| 横幅距离 / 已耗时 | 至少 **14 px** | FONT_MEDIUM；按新布局作为紧凑路线元数据 |
| 指标标签、Zone 编号、关键状态 | 至少 **14 px** | FONT_MEDIUM；缩短标签而不缩小字体 |
| 单位、坐标、路线辅助说明 | 至少 **12 px** | FONT_SMALL；不能在这里藏告警或关键状态 |

以上字高适用于当前官方 Edge 840 设备包的英文字体，需由模拟器原生截图复核；其他语言、固件或字体必须重新测量。

- 每次用 `dc.getTextWidthInPixels()` 检查实际字符串，保留完整的 108 px 列宽约束。[官方绘图 API](https://developer.garmin.com/connect-iq/api-docs/Toybox/Graphics/Dc.html)。
- 文本超长优先简化：距离数值可去掉小数；横幅用 `当前 / 总距 km` 表示距离，用 TIME 标注含暂停的已耗时。不得为了塞入文本一路降到 XTINY。
- 主数值超出受支持的显示宽度时使用同层级 `--`，而不是输出无法辨认的细小数字。
- 保持数字基线稳定，不让每秒变化的数字引起列位移。
- 灰色缺失状态也必须有足够对比度；零功率是有效数值，不能与缺失状态混同。

## 对比度与冗余编码

白底，主要文字用 `#15212B`，标签用 `#354550`。Zone 文本颜色采用下列较深的色值，避免亮黄、浅灰数字在白底上消失。

| 区间 | 色值 | 编码 |
| --- | --- | --- |
| Z1 | `#55616A` | 灰 + Z1 |
| Z2 | `#005AA8` | 蓝 + Z2 |
| Z3 | `#006B3C` | 绿 + Z3 |
| Z4 | `#8F5B00` | 深赭黄 + Z4 |
| Z5 | `#B62612` | 红 + Z5 |
| Z6 | `#8620A0` | 紫 + Z6 |
| Z7 | `#A61561` | 洋红 + Z7 |

项目采用的屏幕色值检查基线是文字与白底 **至少 4.5:1 的 sRGB 对比度**。这只是计算检查，不等于反射式 LCD 在阳光、眼镜和运动条件下的可读性保证。色值必须经过实际面板观察。

- Zone 同时用**数值颜色 + Z 编号 + 4 px 色条**，不只靠颜色区分。
- 路线用深色 2 px 轮廓保持完整形状；已骑与未骑用区域填色区分，当前位置有 3 px 竖线和带白色隔离圈的圆环。
- OFF COURSE / GPS 缺失必须以文字说明并隐藏位置标记，不能用一个难辨认的小色点代替。

## 当前页面的像素预算

| 区域 | 关键坐标 |
| --- | --- |
| 心率 / 功率标签 | `y=8`，心率在左、功率在右 |
| 主数字 | `y=32` |
| 单位 / Zone | `y=92 / 90` |
| Zone 色条 | `y=116, h=4` |
| 踏频标签 / 数值 | `y=124 / 144`，rpm 辅助单位位于右侧 |
| 档位 | `x=150`，说明 `y=124`、较小的 F/R 档位 `y=146` |
| 底部横幅分隔 | `y=184, h=2` |
| 坡度 / 距离 | 标题/距离 `y=192`，坡度数值 `y=214` |
| 已耗时 | 数值 `y=216`，TIME 辅助说明 `y=218` |
| 海拔绘图区 | `x=16…228, y=250…312`，宽 213 列，高 63 像素（含端点） |

曲线垂直映射上下各留 8 px，确保 marker 的白色隔离圈不被截断。缓存静态剖面坐标，骑行时只更新已骑区域和标记。

## 验收

本次检查状态：新版 demo/live 构建、5 项 Garmin VM 测试、3 项 Python 测试通过；关键标签的离线字体宽度估算落在列宽内，Zone 色值计算检查通过。[新版矢量设计稿](design/summit-v2.svg)和[246 × 322 设计预览](design/summit-v2-preview.png)可用于结构审阅。Mac 锁屏阻止了新版原生截图检查，旧截图仅作为 8 px 字高的问题基线，**设计预览不是模拟器截图，新版原生画面和实机验证尚未完成**。

1. 用原生 246 × 322 截图检查标签、四位数功率、`99:59:59`、缺失传感器、GPS 缺失、偏航和路线首尾；不以 Retina 放大窗口替代 1:1 检查。
2. 原图是验收来源；放大只用 nearest-neighbor 整数倍观察像素，不使用平滑插值证明线条清楚。
3. 记录可见字高、最小线宽、标记占位和色值对比度。几何使用整数坐标，禁用原语抗锯齿依赖；设备原生字体的光栅方式由 SDK 管理。
4. 灰度条件下仍可通过 Z 标签、线形、位置圆环和明确文字理解状态。
5. 实机以约 40–60 cm 的常用车把视距，在太阳光、阴影、戴骑行眼镜和合理安全的骑行条件下确认可读性；未通过前不能宣称“实骑已验证”。
