# Edge 840 原生像素规则（v0.3.3）

项目设计基线，适用于246×322单字段全屏。不是Garmin官方最小尺寸规定。[当前矢量稿](design/summit-interactive.svg)。

- 内容外边距2 px；Lap顶帽极端位置仍至少留1 px。竖分隔统一x122，宽2 px。
- 主数字58 px，左对齐x2/x126、baseline44，三位数字可见字形顶部约y2；四位功率回退36 px以避让雷达。
- 右上x218…245/y0…33保持空白。红心16×14 px、闪电14×16 px，均在数字右下侧，底端y52。
- Zone编号28 px加粗、baseline80，右对齐x120/x244；单位18 px。色条x2/x126、y88，118×6 px；当前Zone位置黑色竖线3×10 px。
- 中间左2×2：列中心x31/x92，标签baseline114/174、数值153/212；数值38 px常规。窄格先舍去小数，不裁切数字。
- 右中：x126…244；标题baseline113，计时140（32 px，超长30/26 px），均功率182（54 px，四位36 px），距离212（数字32 px、mi18 px）。AVG/W紧随功率数字，间距3 px。
- 图区从y220开始；分隔x2…243。范围左对齐x2、时钟右对齐x244，baseline238，均18 px。没有总时长与底栏文字。
- 功率图x4…242、y243…319，高77 px；曲线和Lap边界延伸到319，底部留下2 px。FTP虚线和Z2实线随新纵轴映射，阈值不变。
- 图标和曲线启用原生图形抗锯齿；字体采用灰度覆盖率字库并开启抗锯齿导入、按实际白底绘制。整数像素上的色条和分隔线保持锐利。
- 白底，主要文字#15212B，辅助#354550；图填充白底80%不透明。颜色分组与数据口径见README。

点击区：功率(124,0)–(246,98)，统计(124,102)–(246,214)，图表(0,220)–(246,320)，右/下界不含。图表最底部现在也能切换范围；最后2 px留白不响应。切换不清空数据，默认3s/All/5m。
