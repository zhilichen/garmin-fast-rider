# Edge 840 原生像素规则（v0.3.15）

项目设计基线，适用于246×322单字段全屏。[当前矢量稿](design/summit-interactive.svg)。原生模拟器截图用于核对真实字体；SVG为布局参考。

- 外边距2 px；上下竖分隔统一x112、宽2 px，从x107向右回调5 px。左内容x2起、宽108 px；右内容x116起、宽128 px。
- 主数字58 px，左对齐x2/x116，baseline43；心率三位数字字符间距收紧3 px，四位功率36 px回退。右上x218…245/y0…33保持空白。
- 红心16×14、闪电14×14在baseline62单位行，分别左对齐x2/x116，与主数值的实际字形左边缘对齐。心率仅显示红心，去掉bpm；功率显示闪电+4 px间距+3s/10s，去掉W。Zone为16 px加厚小Z+44 px区号，总宽31 px、baseline66；四位主值时10/26 px，总宽20 px。心率Zone右对齐x110，功率右对齐x244。
- 色条y76、h6，心率x2/w108、功率x116/w128；4×22 px位置标记按各自条宽映射，上下8px黑色、中段6px白色。
- 实时左列上gear、下grade，中心x26、文字预算48 px；右列上rpm、下mph，中心x81、预算58 px。标签baseline106/170，数字149/212。38 px加粗数字按真实字形边界排列、字间1 px，120rpm与22.4mph均保持38 px。超宽值回退32/30/26 px；速度始终保留一位小数，坡度取整数，负零显示0。坡度色彩按原始估值判定。
- 右中标题x116/baseline105，时长右对齐244/baseline132。均功率+AVG/W整组在128 px面板内居中，间距3 px。距离+mi+剩余距离同样整组居中，全部字形及单位前后均1 px空隙。优先完整小数，32/24、30/22、26/21 px成对回退；`300.5mi(-200.5)`使用26/21 px，宽127 px。mi18 px常规，剩余数字加粗、括号常规。
- 图头baseline238：爬升x2，带蓝色14×14 px闪电的`< ⚡ 5m >`（20m/All同格式）整组居中x123，完整AM/PM时钟右对齐244；文字18 px，爬升数字粗体、ft常规。
- 功率图x4…242/y243…319，高77 px；FTP虚线、Z2实线及Lap标记保持原规则。字库PNG像素与原字形比例保留，按实际ink裁剪绘制白底抗锯齿，底部额外保留1 px原生栅格化余量；BMFont保留完整advance，避免导入时裁断右沿。
- 高饱和配色和90%图表填充保持原规则，见README。

点击区：功率(114,0)–(246,90)，统计(114,91)–(246,214)，图表(0,220)–(246,320)，右/下界不含。x112…113为分隔，不响应；左侧x<112/y<214双击车铃。默认3s/All/5m。

[长里程原生截图](fastrider-edge840-v0313-long.png)包含300.5mi(-200.5)、120rpm、22.4mph、6%合成数据。真实雷达覆盖和户外可读性仍需Edge840观察。

字体裁剪回归：[修复前](font-probe-v0315-before.png) / [修复后](font-probe-v0315-after.png)。每组T/D/P分别为text/digits/packed，R为相同字体的完整绘制参考；16组字体共44组原生对照，修复前41组丢底部一行，修复后44组全部逐像素一致。小Z只比较T与R。
