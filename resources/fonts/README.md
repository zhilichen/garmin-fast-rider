# Bitmap glyph subsets

Generated by `scripts/generate-fonts.py` from the Garmin Connect IQ development installation's `Fonts/` directory. The app packages small BMFont PNG/FNT subsets only; it does not include TTF source fonts or require system fonts at runtime.

- Primary49: Garmin Roboto Bold, numeric primary readings.
- Live33: Roboto Condensed Regular, live readings.
- Average44 / Average32: Roboto Condensed Bold, lap/ride average power and its four-digit fallback.
- Meta18 / Chart20 / Stats26: DejaVu Sans Condensed SemiBold, labels and compact statistics.

Each font uses `base = size`, allowing the drawing helper to position all text by its visible baseline, matching the approved SVG. Font metrics are checked in the Garmin VM. Regeneration requires Pillow; ordinary builds consume the checked-in generated assets.
